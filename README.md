# OVERGLOW ⚡ — 3D Battle Royale (офлайн)

**Полностью офлайновый 3D battle-royale шуттер для Android в духе PUBG Mobile** —
без единой внешней зависимости и без единого загруженного ассета. Вся графика,
текстуры и звуки синтезируются кодом при старте. Пятьдесят бойцов, самолёт,
свободное падение, парашют, дома с дверями, лут, оружие с обвесами, баллистика
с реальными пулями, транспорт, сжимающаяся зона, боты — и тач-управление,
повторяющее схему PUBG Mobile: стик слева, обзор справа, кнопки справа,
гироскоп.

* **Жанр:** battle royale / TPP-FPS
* **Управление:** мультитач + гироскоп (схема PUBG Mobile, см. ниже)
* **Графика:** OpenGL ES 2.0, процедурные материалы (albedo + normal-карты)
* **Звук:** синтез PCM в коде, 3D-панорамирование
* **Платформа:** Android 8.0+ (minSdk 26), ландшафтный режим, ноль зависимостей

## Управление (схема PUBG Mobile)

Все действия разнесены по зонам и работают одновременно (мультитач до 10 пальцев):

| Зона | Действие |
|---|---|
| Левый нижний квадрант (кроме кнопок) | **плавающий стик движения**; довести до внешней границы = **СПРИНТ** (долгое удержание = авто-бег) |
| Правая половина экрана | **обзор камеры** перетаскиванием; чувствительность падает в ADS автоматически |
| ОГОНЬ (большая справа) | тап = одиночные, удержание = автострельба (у оружия с режимом) |
| ПРИЦЕЛ | переключатель прицеливания; зум зависит от обвеса (Red Dot…8x) |
| СТОЙКА | цикл присед ↔ стойка; долгое нажатие = прыжок; в прыжке — лечь |
| ПИК L / R | тап = фиксация наклона, удержание = наклон до отпускания |
| ПЕРЕЗАРЯДКА / 1 / 2 | перезарядка; смена оружия кнопками слотов или тапом по подписям |
| ГРАНАТА | удержание — прицельная дуга и сила, отпускание — бросок |
| ВЗАИМД. | контекстная кнопка: двери, лут рядом, транспорт |
| КАМЕРА | TPP ↔ FPP; в TPP заодно смена плеча |
| Газ / тормоз-реверс / ручник / выход / гудок | вождение; стик = руль, камера следует за машиной |
| В САМОЛЕТЕ | тап по полосе JUMP — выброска; в падении стик = планирование, кнопка РАСКРЫТЬ (авто на 50 м) |
| Гироскоп | прицеливание наклоном телефона (режим и чувствительность в настройках) |

Реализация: `MobileInputController` (ролевой мультитач — каждый палец привязан
к кнопке/стику/обзору, раскладки меняются по режиму: пеший / машина / падение /
самолёт), а рисует кнопки `PUBGTouchHUD` из той же геометрии `bx/by/br`, поэтому
хитбоксы и картинка не разъезжаются никогда.

## Графика: процедурные текстуры

Никаких файлов картинок — материал каждого объекта генерируется шумовыми
алгоритмами `TextureForge.java` (albedo + normal-карты с рельефом, шероховатость
и металличность на материал, тайлинг в мировых координатах для земли и стен):

* трава, земля, асфальт, бетон, кирпич, штукатурка, песчаник, дерево, доски,
  металл, жесть, ржавчина, стекло, вода, резина;
* ткань, камуфляж, кевлар, кожа, пластик, золото и драконья чешуя — скины оружия;
* небо-градиент с солнцем, блибовые тени, динамический FOV, ADS-зум, вспышки
  выстрела, трассеры, ударные волны взрывов, мягкий туман по расстоянию и ACES.

Меши строит `ModelGenerator` (солдаты с шарнирными ногами и руками, оружие по
модулям, техника с поворотными колёсами, самолёт, парашют, двускатные крыши,
пропсы), рельеф — единой сеткой по высотам карты, дороги — лентами по сплайну.
`GLUtil` — шейдер с PBR-подобной моделью света.

## Механики боя

* Баллистика: летящие пули + CCD-сегменты (пуля не «пролетит» бота между
  тиками), гравитация и падение скорости, свист рикошетов, приведка 100–400 м;
* Хитбоксы голова/торс/конечности, броня и шлемы поглощают процент, хедшот-маркер;
* 7 стволов (M416, AKM, MP5K, Kar98k, S686, UZI, DRL) с обвесами
  (дульник/рукоять/магазин/оптика) и скинами;
* Паттерн отдачи с восстановлением, разброс от движения и стойки;
* Гранаты: таймер, урон по сфере, тряска экрана;
* Зона: белый/синий круги, урон по фазам, таймер в HUD и на миникарте;
* Аирдроп с дымным маркером; транспорт (багги/UAZ) с физикой, топливом,
  тараном и поломкой;
* Боты: ИИ с приоритетами (лут → ротация в зону → бой), лечатся, стреляют
  очередями, падают и превращаются в ящики с лутом.

## HUD и лобби

Canvas-HUD поверх GL: миникарта с дорогами/постройками/зонами, компас-лента с
градусами, крест с динамическим разбросом, оптика 4x/8x с сеткой поправок,
полоски HP/брони/усиления, патроны и слоты, список лута рядом с дистанцией,
киллфид, дуга входящего урона, бар лечения, спидометр и топливо в машине,
высотомер в прыжке. В лобби: смена скинов, качество графики, гироскоп,
чувствительность камеры и гироскопа, размер кнопок, инверсия оси Y, звук —
применяются на лету.

## Сборка

Проект собирается «как есть»: **Gradle 9.0.0 + AGP 8.13.0 + JDK 17 + compileSdk 36**.
Для старых IDE — совместимый профиль:

```sh
sh scripts/switch-profile.sh androidide   # Gradle 8.6 + AGP 8.2.2
sh scripts/switch-profile.sh modern       # вернуть современный профиль
```

```bash
./gradlew assembleDebug
# → app/build/outputs/apk/debug/app-debug.apk
```

CI-рецепт: `ci/build-apk.yml` (скопировать в `.github/workflows/` один раз).

## Как играть

1. Лобби → «НАЙТИ МАТЧ» → ты в самолёте. Тапни **ВЫПРЫГНУТЬ**, планируй стиком,
   раскрой парашют (кнопка или авто на 50 м), садись на двор или крышу.
2. Обыскивай дома: кнопка ВЗАИМД. поднимает лут, двери открываются сами рядом.
   Тап по подписи слота 1/2 — смена ствола.
3. Стреляй: тап — одиночные, удержание ОГОНЬ — авто. В прицеле — ПРИЦЕЛ или
   гироскоп. Из-за угла — пик L/R.
4. Зона сжимается: смотри таймер и синий круг на миникарте; машины ускоряют
   ротацию; аирдроп даёт топ-лут, но приманивает людей.
5. Последний выживший получает **WINNER WINNER — CHICKEN DINNER**.
