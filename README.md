# OVERGLOW ⚡

**Неоновая survivors-выживалка для Android.** Один палец — и толпа отступает:
веди светящееся ядро сквозь глитч-монстров, оружие бьёт само, собирай кристаллы
опыта и собирай безумную сборку усилений. Продержись 20 минут и убей Короля
глитчей — или падай, но возвращайся сильнее: золото остаётся с тобой навсегда.

* **Жанр:** bullet-heaven / survivors-like (в духе Vampire Survivors)
* **Стиль:** неон и свечение на почти чёрном фоне
* **Управление:** виртуальный стик одним пальцем — первый тач в любом месте экрана
* **Язык:** русский по умолчанию, английский переключается в настройках
* **Платформа:** Android 8.0+ (minSdk 26), портрет и ландшафт

## Контент

* **4 героя:** Пульс (баланс), Тесла (стеклянная пушка), Бастион (танк),
  Ведьма Бездны (открывается в магазине)
* **12 оружий** до 8 уровня каждое (6 слотов): Импульсная винтовка, Цепная
  молния, Орбитальные клинки, Взрыв Новы, Сферы Бездны, Лазерный луч, Ракеты,
  Ледяные осколки, Бумеранг-диски, Гроза, Плазменная аура, Чёрная дыра
* **★ Пробуждение**: оружие 8-го уровня можно пробудить — урон ×1.6 навсегда
* **🔮 10 реликвий** с уникальными эффектами: двойной выстрел, вампиризм,
  стеклянное сердце (+40% урона / −25% HP), хроносфера, золотая жила и др.
  Падают с боссов и из сундуков элит
* **🏆 10 достижений** с наградами золотом (экран ★ в меню)
* **9 пассивок** до 5 уровня: урон, перезарядка, HP, скорость, магнит, броня,
  опыт, регенерация, криты
* **9 видов врагов** + элиты каждые 90 секунд (сундук с добычей) + мини-босс
  на 5:00 + **босс** на 10:00 (кольца пуль / рывок / саммоны) + финальная
  **Королева Роя** на 20:00 (спиральный обстрел / телепорты)
* **Случайные события:** Золотой жадина (убей беглеца — золото), Метеоритный
  дождь (телеграфы + залп), Орда летучих мышей; **наплывы** волн со
  стрелкой-предупреждением
* Комбо-счётчик до ×2.5 золота, killstreak-баннеры (РАЗГРОМ! → НЕОНОВЫЙ
  АПОКАЛИПСИС!), hit-stop на критах, щит и ×2-золото пикапы, красная
  виньетка при низком HP, панель билда в паузе
* **Мета-магазин:** 5 треков вечных усилений за золото (HP, урон, скорость,
  магнит, жадность) + открытие героев
* **Победа** на 20:00 + режим **бесконечности** после неё
* Сок: параллакс-туманности и пыль, двойной glow, трейлы, спавн-анимации
  врагов, взрывы с ударной волной, цифры урона, криты с hit-stop, тряска,
  slow-mo, глитч-логотип, баннеры событий, вибрация

## Технологии (ноль зависимостей, ноль ассетов)

Вся игра — чистый Java + Canvas, без единой внешней библиотеки и без единого
файла графики/звука:

| Что | Как сделано |
|---|---|
| Графика | SurfaceView + свой поток, fixed timestep 60 Гц |
| Свечение | прекеш glow-спрайтов (RadialGradient → Bitmap) |
| Коллизии | пространственная сетка 30×30, пулы объектов |
| Звук и музыка | синтез PCM в коде: AudioTrack-микшер, 12 голосов SFX + секвенсорный луп ~130 BPM |
| UI | всё рисуется на Canvas — ни одного layout-XML |
| Сохранения | SharedPreferences + JSON (золото, меты, герои, статистика) |

## Сборка

### На телефоне (AndroidIDE / AIDE-подобные IDE)

Проект собирается «как есть» — тот же рецепт, что и проверенный шаблон:
**Gradle 9.0.0 + AGP 8.13.0 + JDK 17 + compileSdk 36**. Открой папку проекта
в IDE и нажми Sync + Run.

Если IDE старая и не тянет Gradle 9 — переключись на совместимый профиль:

```sh
sh scripts/switch-profile.sh androidide   # Gradle 8.6 + AGP 8.2.2
sh scripts/switch-profile.sh modern       # вернуть современный профиль
```

### На компьютере

```bash
./gradlew assembleDebug
# → app/build/outputs/apk/debug/app-debug.apk
```

### GitHub Actions (по желанию)

CI-рецепт лежит в `ci/build-apk.yml` (токен бота не имеет права создавать
`.github/workflows/` — скопируй файл туда вручную один раз, дальше каждый пуш
будет собирать APK в артефакты **Overglow-debug-apk**).


## Как играть

* Веди пальцем из любой точки экрана — это джойстик. Короткий тап — пауза.
* Оружие стреляет автоматически: твоё дело — позиционирование.
* Кристаллы → уровни → выбор 1 из 3 карточек. Максимум 4 оружия и 9 пассивок.
* Элиты (фиолетовые, в золотой короне) роняют сундуки.
* Умер — не беда: всё заработанное золото копится на вечные усиления.
